## Letakkan File Video Di Sini

Format yang didukung:
- MP4 (.mp4) - Recommended
- WebM (.webm)
- Ogg (.ogv)

Contoh penamaan:
- video/perjalanan1.mp4
- video/momen2.mp4
- video/cerita3.mp4

**Tips:**
- Gunakan format MP4 untuk kompatibilitas terbaik
- Compress video untuk loading lebih cepat
- Ukuran file maksimal disarankan 50MB per video

**Edit script.js untuk menambahkan video baru:**
```javascript
{
    type: 'video',
    src: 'video/nama-file-anda.mp4',
    caption: 'Deskripsi video'
}
```
