## Letakkan File Foto Di Sini

Format yang didukung:
- JPG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp)

Contoh penamaan:
- foto/momen1.jpg
- foto/kenangan2.jpg
- foto/bersama3.png

Pastikan ukuran file tidak terlalu besar (compress jika perlu untuk loading lebih cepat).

**Edit script.js untuk menambahkan foto baru:**
```javascript
{
    type: 'image',
    src: 'foto/nama-file-anda.jpg',
    caption: 'Deskripsi kenangan'
}
```
